# NTP (Network Time Protocol)

**NTP** es el protocolo utilizado para sincronizar la hora de los sistemas con servidores de tiempo de referencia. Es fundamental en servidores de aplicaciones, ya que muchos procesos (certificados TLS, logs, bases de datos replicadas...) dependen de que la hora sea correcta.

## ¿Por qué es importante?

- Un certificado **TLS** puede ser rechazado si la hora del sistema está muy desincronizada.
- Los **logs** de varios servidores deben tener marcas de tiempo coherentes para poder analizarlos conjuntamente.
- Sistemas distribuidos y bases de datos replicadas requieren consistencia horaria.

## Instalación y uso de `chrony` en Debian/Ubuntu

```bash
sudo apt update
sudo apt install chrony -y
sudo systemctl enable --now chrony
```

## Comprobar el estado de sincronización

```bash
chronyc tracking
chronyc sources
```

## Sincronización manual puntual

```bash
sudo chronyd -q 'server pool.ntp.org iburst'
```
