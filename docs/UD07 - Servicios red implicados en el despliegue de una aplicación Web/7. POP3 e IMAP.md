# POP3 e IMAP

Mientras que **SMTP** se encarga del **envío** de correo, **POP3** e **IMAP** son los protocolos utilizados para la **recepción y consulta** del correo electrónico por parte del cliente.

## POP3 (Post Office Protocol v3)

- Descarga los correos del servidor al cliente y, por defecto, **los elimina del servidor**.
- Pensado para acceder al correo desde un único dispositivo.
- Puerto por defecto: **110** (o **995** sobre SSL/TLS).

## IMAP (Internet Message Access Protocol)

- Mantiene los correos **sincronizados en el servidor**, permitiendo acceder desde varios dispositivos a la vez.
- Es el protocolo recomendado actualmente frente a POP3.
- Puerto por defecto: **143** (o **993** sobre SSL/TLS).

## Comparativa

| Característica          | POP3                  | IMAP                         |
|---------------------------|------------------------|---------------------------------|
| Sincronización multi-dispositivo | No               | Sí                               |
| Los correos permanecen en el servidor | No (por defecto) | Sí                        |
| Puerto (sin cifrar)        | 110                    | 143                              |
| Puerto (con SSL/TLS)       | 995                    | 993                              |

## Instalación de un servidor IMAP/POP3 (Dovecot)

```bash
sudo apt update
sudo apt install dovecot-imapd dovecot-pop3d -y
sudo systemctl enable --now dovecot
```
