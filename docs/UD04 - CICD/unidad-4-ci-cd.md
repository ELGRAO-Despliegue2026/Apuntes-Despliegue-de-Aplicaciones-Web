# Unidad 4 — CI/CD

Objetivos

- Comprender y diseñar pipelines de Integración Continua y Despliegue Continuo.
- Implementar pipelines que automaticen build, tests y despliegue.

Contenidos

- Conceptos CI, CD y herramientas (Jenkins, GitHub Actions, GitLab CI).
- Pipelines: build, test, pack, publicar artefactos y desplegar.
- Almacenamiento de artefactos (Nexus, Artifactory) y gestión de versiones.
- Estrategias de despliegue: blue/green, canary, rollback.
- Seguridad en pipelines y pruebas automatizadas.

Prácticas sugeridas

- Crear un pipeline que construya, ejecute tests, cree una imagen Docker y despliegue a staging.
- Añadir pasos de pruebas de seguridad o análisis estático.

Recursos

- Documentación de Jenkins, GitHub Actions y GitLab CI.
