# Administración de Servidores de Aplicaciones

## Objetivos

- Entender qué es un servidor de aplicaciones y en qué se diferencia de un servidor web.
- Conocer distintos tipos de servidores de aplicaciones y su despliegue (Java, Node.js, PHP).
- Aprender a desplegar, configurar y monitorizar aplicaciones en estos entornos.

## Contenidos de la unidad

- Servidores Java (Tomcat, Jetty).
- Entornos Node.js (PM2, systemd).
- PHP-FPM.
- Formatos de despliegue (WAR, JAR, paquetes Node/PHP).
- Gestión de logs, sesiones y recursos.
- Escalado básico y clustering.
- Monitorización y alertas.

## Recursos

- Documentación oficial de Tomcat.
- Documentación oficial de Node.js y PM2.
- Documentación oficial de PHP-FPM.
