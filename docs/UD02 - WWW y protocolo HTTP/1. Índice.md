# Índice

En esta unidad estudiaremos los fundamentos de la **World Wide Web (WWW)** y del protocolo **HTTP**, base de toda comunicación entre clientes y servidores web. Comprenderemos cómo se organizan las aplicaciones web (arquitecturas), cómo viajan los datos por la red (protocolos de internet) y cómo funciona en detalle el protocolo HTTP, junto con su variante segura HTTPS.
