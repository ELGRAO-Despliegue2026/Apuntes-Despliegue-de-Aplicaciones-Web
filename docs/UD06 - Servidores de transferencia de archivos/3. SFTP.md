# SFTP (SSH File Transfer Protocol)

**SFTP** es un protocolo de transferencia de ficheros que funciona **sobre SSH**, por lo que toda la comunicación (credenciales y datos) viaja **cifrada**.

## Características

- Utiliza una **única conexión** (puerto 22, el mismo que SSH).
- No debe confundirse con **FTPS** (FTP sobre SSL/TLS), que es un protocolo diferente.
- Requiere tener un servidor **SSH** instalado y en ejecución.

## Instalación y uso (servidor SSH)

```bash
sudo apt update
sudo apt install openssh-server -y
sudo systemctl enable --now ssh
```

## Conexión desde el cliente

```bash
sftp usuario@miservidor.com
```

Comandos básicos dentro de una sesión SFTP:

```text
ls              # Listar archivos remotos
lls             # Listar archivos locales
put fichero.txt # Subir un fichero
get fichero.txt # Descargar un fichero
cd carpeta      # Cambiar de directorio remoto
exit            # Salir
```

## Transferencia directa sin sesión interactiva

```bash
sftp usuario@miservidor.com:/ruta/remota/fichero.txt .
```

## FTP vs SFTP

| Característica       | FTP            | SFTP                |
|------------------------|----------------|------------------------|
| Cifrado                | No             | Sí (sobre SSH)         |
| Puertos                | 20/21 (+rango) | 22                     |
| Autenticación segura    | No             | Sí                     |
