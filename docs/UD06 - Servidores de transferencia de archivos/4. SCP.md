# SCP (Secure Copy Protocol)

**SCP** permite copiar ficheros entre máquinas de forma segura, también utilizando **SSH** como transporte.

## Características

- Cifrado mediante SSH (puerto 22).
- Más simple que SFTP: no ofrece sesión interactiva, solo copia ficheros.
- Sintaxis similar al comando `cp` de Linux.

## Copiar un fichero local a un servidor remoto

```bash
scp fichero.txt usuario@miservidor.com:/ruta/destino/
```

## Copiar un fichero remoto a la máquina local

```bash
scp usuario@miservidor.com:/ruta/origen/fichero.txt .
```

## Copiar una carpeta completa (recursivo)

```bash
scp -r carpeta/ usuario@miservidor.com:/ruta/destino/
```

## Especificar un puerto distinto

```bash
scp -P 2222 fichero.txt usuario@miservidor.com:/ruta/destino/
```

## SCP vs SFTP

| Característica       | SCP                  | SFTP                        |
|------------------------|------------------------|---------------------------------|
| Sesión interactiva      | No                      | Sí                               |
| Operaciones soportadas  | Solo copiar             | Listar, renombrar, borrar, copiar... |
| Velocidad               | Ligeramente más rápido  | Algo más lento (más funciones)   |
