# Rsync

**Rsync** es una herramienta de sincronización de ficheros y directorios, muy utilizada para copias de seguridad y despliegues, ya que solo transfiere las **diferencias** entre origen y destino.

## Características

- Puede funcionar en local, o de forma remota combinado con **SSH**.
- Transferencia incremental: solo copia los bloques de datos que han cambiado.
- Permite sincronización bidireccional controlando origen y destino.

## Instalación

```bash
sudo apt install rsync -y
```

## Sincronización local

```bash
rsync -av origen/ destino/
```

- `-a`: modo archivo (conserva permisos, fechas, enlaces...).
- `-v`: modo detallado (*verbose*).

## Sincronización remota sobre SSH

```bash
rsync -avz -e ssh origen/ usuario@miservidor.com:/ruta/destino/
```

- `-z`: comprime los datos durante la transferencia.
- `-e ssh`: indica que se use SSH como transporte.

## Eliminar ficheros que ya no existen en el origen

```bash
rsync -av --delete origen/ destino/
```

## Simulación sin aplicar cambios (modo prueba)

```bash
rsync -avn origen/ destino/
```

- `-n`: *dry-run*, muestra qué haría sin ejecutar realmente la copia.

## Comparativa de herramientas de transferencia

| Herramienta | Cifrado | Transferencia incremental | Uso típico                  |
|--------------|:---:|:---:|---------------------------------|
| FTP          | No   | No   | Transferencias simples, no seguras |
| SFTP         | Sí   | No   | Transferencia segura interactiva |
| SCP          | Sí   | No   | Copia puntual y rápida de ficheros |
| Rsync        | Sí (con SSH) | Sí | Sincronización y copias de seguridad |
