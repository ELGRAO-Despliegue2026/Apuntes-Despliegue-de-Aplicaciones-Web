# 1. Git

Git es un **sistema de control de versiones distribuido**: permite registrar el historial de cambios de un proyecto, trabajar en paralelo con otras personas y volver atrás si algo sale mal.

## Ejemplo de flujo entre áreas

```mermaid
sequenceDiagram
    participant Working Directory
    participant Staging Area (Index)
    participant Local Repository (Head)
    participant Remote Repository (Head)
    Working Directory ->> Staging Area (Index): git add
    Staging Area (Index) ->> Working Directory  : git restore
    Staging Area (Index) ->> Local Repository (Head) : git commit
    
    Local Repository (Head) ->> Remote Repository (Head): git push
    Remote Repository (Head)->> Local Repository (Head): git pull
    Local Repository (Head) ->> Working Directory : git checkout
```
