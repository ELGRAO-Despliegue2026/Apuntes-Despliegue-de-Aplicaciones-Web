# Instalación

Docker se distribuye en dos variantes principales:

- **Docker Desktop**: aplicación con interfaz gráfica para Windows y macOS (también disponible en Linux). Incluye Docker Engine, Docker Compose y una GUI de gestión.
- **Docker Engine**: instalación en línea de comandos, típica en servidores Linux.

## Instalación en Linux (Debian/Ubuntu)

1. Actualizar los paquetes e instalar dependencias necesarias:

```bash
sudo apt update
sudo apt install ca-certificates curl gnupg
```

2. Añadir la clave GPG oficial de Docker:

```bash
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
```

3. Añadir el repositorio oficial de Docker:

```bash
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

4. Instalar Docker Engine, la CLI y el plugin de Compose:

```bash
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

## Instalación en Windows y macOS

Docker puede correr en Windows gracias principalmente a WSL 2 (Windows Subsystem for Linux 2). El funcionamiento es sencillo: Windows inicia un kernel de Linux liviano sobre el hipervisor ligero de WSL 2. A continuación, Docker Desktop se ejecuta como una aplicación nativa de Windows que envía las órdenes del cliente de Docker (como `docker run`, `docker-compose`, etc.) al *demonio* de Docker dentro de WSL 2.

Descargar e instalar **Docker Desktop** desde [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop). El instalador incluye Docker Engine, Docker CLI y Docker Compose.

!!! note "Windows y WSL2"
    En Windows, Docker Desktop requiere **WSL2** (Windows Subsystem for Linux 2) como backend. El propio instalador ofrece habilitarlo si no está activo.

## Comprobar la instalación

```bash
docker --version
docker compose version
```

Ejecutar el contenedor de prueba oficial:

```bash
docker run hello-world
```

Si todo está correcto, Docker descargará la imagen `hello-world` y mostrará un mensaje de confirmación.


## Verificar que el servicio está activo (Linux)

```bash
sudo systemctl status docker
sudo systemctl enable docker    # arrancar Docker automáticamente al iniciar el sistema
```
