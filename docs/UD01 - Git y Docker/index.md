# Unidad 1 — Git y Docker

Objetivos

- Entender y aplicar control de versiones con Git.
- Crear y gestionar imágenes/contenedores Docker y dockerizar aplicaciones.

Contenidos

- Git: commits, ramas, merges, pull requests, tags, flujos de trabajo (feature-branch, Git Flow).
- Plataformas: GitHub / GitLab / Bitbucket; gestión de repositorios remotos.
- Docker: imágenes, contenedores, Dockerfile, builds, registries.
- Docker Compose: servicios, redes y volúmenes.

Prácticas sugeridas

- Crear un repositorio con una aplicación simple, usar ramas y pull requests.
- Dockerizar la aplicación con Dockerfile y orquestarla con docker-compose.

Recursos

- Documentación oficial de Git y Docker.
