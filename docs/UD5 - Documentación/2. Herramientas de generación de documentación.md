# Herramientas de generación de documentación

La documentación es una parte esencial del ciclo de vida de cualquier aplicación software. Permite que otros desarrolladores, usuarios o administradores comprendan cómo funciona, se instala, se configura y se mantiene una aplicación.

## ¿Qué es un generador de documentación?

Un generador de documentación es una herramienta que, a partir de comentarios en el código fuente, ficheros de texto plano (Markdown, reStructuredText, etc.) o anotaciones específicas, construye automáticamente documentación en distintos formatos (HTML, PDF, man pages, etc.).

## Tipos de herramientas

### Generadores basados en comentarios de código (documentación técnica/API)

Extraen comentarios especialmente formateados directamente del código fuente para generar documentación de referencia (API docs).

- **Javadoc** (Java)
- **Doxygen** (C, C++, Java, PHP, Python...)
- **JSDoc** (JavaScript)
- **phpDocumentor** (PHP)
- **Sphinx + autodoc** (Python)
- **Swagger / OpenAPI** (documentación de APIs REST)

### Generadores de sitios de documentación estática (Markdown/texto)

Permiten escribir documentación en ficheros de texto (normalmente Markdown) y generan un sitio web estático navegable.

- **MkDocs**
- **Jekyll**
- **Hugo**
- **Docusaurus**
- **GitBook**

### Herramientas de documentación colaborativa

- **Wikis** (MediaWiki, DokuWiki)
- **Confluence**
- **Notion**
- **Google Docs / Google Sites**

## Criterios para seleccionar una herramienta

A la hora de elegir una herramienta de generación de documentación conviene valorar:

- **Lenguaje/plataforma** de la aplicación a documentar.
- **Formato de salida** necesario (HTML, PDF, etc.).
- **Facilidad de integración** con el sistema de control de versiones y con la integración continua (CI/CD).
- **Coste** (herramientas libres frente a herramientas de pago).
- **Curva de aprendizaje** y comunidad de soporte.
- **Capacidad de trabajo colaborativo** entre varios autores.

## Ejemplos de uso según plataforma

| Plataforma         | Generador recomendado |
|---------------------|------------------------|
| Java                | Javadoc                |
| Python              | Sphinx                 |
| JavaScript/Node.js  | JSDoc                  |
| PHP                 | phpDocumentor          |
| API REST            | Swagger/OpenAPI        |
| Documentación general/manuales | MkDocs      |
