# 7. Visualización del proyecto

Comandos para consultar el estado y el historial del repositorio sin modificar nada.

## Estado actual: `git status`

Muestra archivos modificados, en staging y sin seguimiento (*untracked*):

```bash
git status
```

## Historial de commits: `git log`

```bash
git log                  # historial completo (autor, fecha, mensaje, hash)
git log --oneline        # una línea por commit (resumen)
git log --graph --oneline --all   # historial gráfico con todas las ramas
```

## Ver diferencias: `git diff`

```bash
git diff                 # cambios en working dir aún no añadidos al staging
git diff --staged        # cambios en staging aún no confirmados (commit)
git diff <commit1> <commit2>   # diferencias entre dos commits
```

## Ver ramas: `git branch`

```bash
git branch        # ramas locales
git branch -a     # locales + remotas
```

## Ver detalles de un commit concreto

```bash
git show <hash-commit>
```

## Ver quién modificó cada línea: `git blame`

```bash
git blame archivo.txt
```

Útil para saber en qué commit y por quién se introdujo un cambio concreto.

## Resumen de comandos de consulta

| Comando            | Uso                                             |
| -------------------- | ------------------------------------------------ |
| `git status`         | Estado actual de los archivos                    |
| `git log`            | Historial de commits                             |
| `git diff`           | Diferencias entre áreas o commits                |
| `git branch`         | Listado de ramas                                 |
| `git show`           | Detalle de un commit                             |
| `git blame`          | Autor/commit de cada línea de un archivo         |
