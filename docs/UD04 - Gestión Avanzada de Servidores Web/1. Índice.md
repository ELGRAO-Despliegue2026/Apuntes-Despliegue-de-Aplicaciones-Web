# Gestión Avanzada de Servidores Web

## Objetivos

- Profundizar en la configuración avanzada de servidores web (Apache/Nginx).
- Aprender a gestionar módulos, rendimiento, seguridad y balanceo de carga.
- Configurar HTTPS mediante certificados digitales.

## Contenidos de la unidad

- Módulos y configuración avanzada del servidor web.
- Optimización del rendimiento (caché, compresión, keep-alive).
- Balanceo de carga y proxy inverso.
- Configuración de HTTPS con certificados SSL/TLS.
- Seguridad básica del servidor web.
