# Gestión Avanzada de Servidores Web

## Objetivos

- Configurar mecanismos de autenticación y control de acceso en Apache.
- Entender qué son los certificados digitales, cómo se obtienen y cómo funcionan.
- Realizar pruebas de funcionamiento del servidor web.
- Establecer mecanismos para asegurar las comunicaciones entre cliente y servidor (HTTPS/TLS).
- Elaborar documentación relativa a la configuración, administración segura y recomendaciones de uso del servidor.
- Realizar los ajustes necesarios para la implantación de aplicaciones en el servidor web.
- Utilizar tecnologías de virtualización en el despliegue de servidores web en la nube y en contenedores.
- Instalar, configurar y utilizar herramientas de gestión de logs, permitiendo su monitorización.
