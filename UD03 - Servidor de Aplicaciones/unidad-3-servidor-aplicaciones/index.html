    Unidad 3 — Servidor de Aplicaciones

    Objetivos

    • Entender distintos tipos de servidores de aplicaciones y su despliegue.
    • Aprender a desplegar aplicaciones Java, Node.js y PHP en entornos adecuados.

    Contenidos

    • Servidores Java (Tomcat, Jetty), Node.js, PHP-FPM.
    • Formatos y despliegue (WAR, JAR, paquetes Node/PHP).
    • Gestión de logs, sesiones y recursos.
    • Escalado básico y clustering.
    • Monitorización y alertas.

    Prácticas sugeridas

    • Desplegar una aplicación Java en Tomcat y una aplicación Node.js con PM2 o systemd.
    • Configurar logging y monitorización simple (prometheus/alertmanager o soluciones básicas).

    Recursos

    • Documentación de Tomcat, Node.js y herramientas de monitorización.
