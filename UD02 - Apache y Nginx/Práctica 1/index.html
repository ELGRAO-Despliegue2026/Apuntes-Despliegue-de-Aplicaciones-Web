    Práctica 1: Creación y Configuración de Máquina Virtual con Debian 13 Mínimo

    Índice

    1. Requisitos previos
    2. Paso 1: Comprobación de la Arquitectura del Sistema Anfitrión
    3. Paso 2: Descarga de la Imagen ISO de Debian 13
    4. Paso 3: Creación de la Máquina Virtual en VirtualBox
    5. Paso 4: Instalación Paso a Paso de Debian 13 Mínimo
    6. Paso 5: Verificación del Entorno sin GUI

    Paso 1: Comprobación de la Arquitectura del Sistema Anfitrión

    Antes de descargar la ISO de Debian 13, es fundamental determinar qué arquitectura tiene el procesador de tu equipo para elegir la imagen adecuada.

    1. Abre la terminal o consola de comandos en tu equipo anfitrión.
    2. Ejecuta el comando:
    uname -m
    1. Interpretación del resultado:
    2. x86_64: Corresponde a la arquitectura amd64 (Intel o AMD de 64 bits). Es el resultado más común en PCs y portátiles habituales.
    3. aarch64: Corresponde a la arquitectura arm64 (Apple Silicon M1/M2/M3/M4, PCs con Qualcomm Snapdragon, Raspberry Pi, etc.).

    Paso 2: Descarga de la Imagen ISO de Debian 13

    1. Accede a la página oficial de descargas de Debian.
    2. Dirígete a la sección de la versión de pruebas/testing (Debian 13 "Trixie") o descarga la ISO de tipo Netinst (instalación por red).
    3. Selecciona la arquitectura obtenida en el Paso 1:
    4. Si el resultado fue x86_64 \(\rightarrow\) Descargar ISO versión amd64.
    5. Si el resultado fue aarch64 \(\rightarrow\) Descargar ISO versión arm64.

    Paso 3: Creación de la Máquina Virtual en VirtualBox

    1. Abre VirtualBox y haz clic en el botón Nueva.
    2. Nombre y sistema operativo:
    3. Nombre: Debian13-Servidor-DAW
    4. Imagen ISO: Selecciona el archivo ISO de Debian 13 descargado.
    5. Tipo: Linux
    6. Versión: Debian (64-bit) o Debian (ARM64) según tu procesador.
    7. Hardware:
    8. Memoria RAM: Asigna mínimo 1024 MB (1 GB) o 2048 MB (2 GB). Al no llevar entorno gráfico, consumirá muy pocos recursos.
    9. Procesadores: 1 o 2 vCPUs.
    10. Disco Duro Virtual:
    11. Selecciona Crear un disco duro virtual ahora.
    12. Tamaño: 15,00 GB (suficiente para el sistema base y el servidor web).
    13. Configuración de Red (Importante):
    14. Selecciona la máquina virtual creada y entra en Configuración > Red.
    15. En el Adaptador 1, asegúrate de tener la opción "NAT". En el Reenvio de puertos tendrás que añadir dos reglas:
    Nombre Protocolo IP anfitrión Puerto anfitrión IP invitado Puerto invitado
    HTTP TCP 127.0.0.1 8080 10.0.2.15 80
    SSH TCP 2222 22

    Paso 4: Instalación Paso a Paso de Debian 13 Mínimo

    1. Inicia la máquina virtual con la ISO insertada.
    2. En el menú de arranque de GRUB, selecciona Install o Graphical Install.
    3. Configuración regional:
    4. Elige el idioma (ej. Spanish - Español).
    5. Selecciona tu ubicación y la distribución del teclado (Español).
    6. Configuración de Red y Usuarios:
    7. Nombre del equipo (Hostname): servidor-apache
    8. Nombre de dominio: (Dejar en blanco)
    9. Contraseña de root: Introduce una contraseña segura para el superusuario y confírmala.
    10. Usuario no privilegiado: Crea una cuenta de usuario estándar (ej. alumno) y asigna su clave.
    11. Particionado del disco:
    12. Método de particionado: Guiado - usar todo el disco.
    13. Selecciona el disco duro virtual creado.
    14. Esquema: Todos los ficheros en una sola partición (recomendado para novatos).
    15. Selecciona Finalizar el particionado y escribir los cambios en el disco y confirma marcando Sí.
    16. Selección de Programas (Paso Clave para versión Mínima):
    17. Cuando aparezca la pantalla "Selección de programas" / "Tasksel":
      • Desmarca: Entorno de escritorio Debian / Debian desktop environment.
      • Desmarca: Cualquier GUI adicional (GNOME, XFCE, KDE, etc.).
      • Marca: Utilidades estándar del sistema (standard system utilities).
      • Marca (Opcional): SSH server (útil para conectarse remotamente).

    Navegación: Usa las flechas para moverte, la Barra Espaciadora para marcar/desmarcar casillas, y la tecla Tabulador para seleccionar el botón Continuar.

    1. Instalación del cargador de arranque GRUB:
    2. Selecciona Sí para instalar GRUB en el unidad principal.
    3. Elige el dispositivo /dev/sda o la unidad virtual correspondiente.
    4. Finalización:
    5. Cuando indique que la instalación ha completado, extrae la ISO virtual y haz clic en Continuar para reiniciar.

    Paso 5: Verificación del Entorno sin GUI

    Una vez reiniciada la máquina virtual, debes comprobar que el sistema ha arrancado correctamente en modo texto/consola:

    1. Verás en pantalla la solicitud de login por CLI: 
      servidor-apache login:
    2. Inicia sesión con el usuario root o el usuario creado.
    3. Comprueba la versión instalada ejecutando: 
      cat /etc/debian_version
    4. Verifica la interfaz de red e IP asignada ejecutando: 
      ip a
